## 👋 关于碎银记

碎银记是一款专注于个人日常收支记录的轻量化记账应用。

由一名**计算机专业大一在读学生**独立开发，没有广告，不收集数据，没有付费会员。所有数据存储在你的设备本地，保护你的隐私。

> 没有 KPI，没有投资人，只有一颗想让你用得顺手的心。

## ✨ v2.0 核心特色

### 🎨 全新交互体验

- **左右滑动切换页面** — 手指在任意页面左右滑动即可切换，底部紫色玻璃指示器实时跟随
- **页面永不回顶端** — 四个页面水平排列、永不卸载，每个页面的滚动位置独立记忆，切走再切回还是原来的位置
- **底部 Dock 栏固定** — 四个导航按钮永远固定在屏幕最底端，随时可点
- **透明状态栏** — 沉浸式设计，状态栏透出页面毛玻璃背景，告别突兀的黑边
- **液态玻璃指示器** — 底部导航的紫色淡色玻璃小方块，跟随选中项丝滑滑动，可拖拽切换
- **iOS Spring 动效** — 全站采用 iOS 弹性动画曲线，操作如丝般顺滑
- **毛玻璃质感** — 顶栏、Dock 栏、统计卡片全部采用 backdrop-filter 毛玻璃效果

### 📊 统计页大升级

- **列表 / 组件双视图** — 一键切换，切换时带缩放动画
- **默认 6 大实用组件** — 智能洞察、支出分类、消费日历、趋势图、支出排行、月度对比
- **可选创意组件** — 碎银诗歌、财务心跳、消费星图、碎银万花筒、消费声纹（自由添加）
- **组件内容填满方框** — 图表、列表自适应填满组件区域，信息密度更高
- **可滚动内容区** — 智能洞察、消费日历、支出排行等组件内部均可上下滑动

### 🪙 碎银时钟

- 实时时钟表盘 + 日期 + 星期
- 右侧轮换文艺诗句，每 4 小时换一句
- 今日支出实时显示，鼓励坚持记账
- **NTP 网络时间校准** — 启动时及每分钟同步网络时间，记账时间精准可靠

### 🎋 碎银签

- 每日可抽一签（上上签 / 上签 / 中签 / 下签）
- 抽签结果当日保留，次日刷新
- 趣味理财寄语，记账之余图个好彩头

## 📥 安装方式

### 方式一：安装 APK（推荐）

1. 下载 `碎银记_v2.0.apk` 到手机
2. 在文件管理器中点击安装
3. 如提示"未知来源"，请在系统设置中允许安装

**系统要求**：Android 7.0 及以上

### 方式二：浏览器使用

1. 下载 `index.html` 到手机
2. 用手机浏览器打开即可使用
3. 可「添加到主屏幕」，体验接近原生应用

## 🔧 技术说明

| 项目 | 说明 |
|------|------|
| 前端 | 纯 HTML / CSS / JavaScript，无框架依赖，单文件运行 |
| 数据存储 | 浏览器 LocalStorage（APK 内 WebView 本地存储） |
| 图表 | 原生 Canvas API 绘制 |
| 时间同步 | HTTP 时间 API，每分钟校准 |
| 构建 | aapt2 + javac(JDK17) + d8 + apksigner |
| 签名 | V1+V2+V3 签名，可正常安装 |

### 从源码构建 APK

```bash
# 依赖：JDK 17、Android SDK (build-tools 34.0.0, platform-34)
cd expense-tracker
bash build_apk.sh
# 输出：xiaozhangben.apk
```
