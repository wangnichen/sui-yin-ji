# 碎银记 v1.4

> 每一笔都值得记录

## 这是什么

碎银记是一款由高考生「我不要芒果」在暑假期间独立开发的个人记账 APP。纯本地存储，无服务器、无账号、无广告，数据只存在你的手机里。

## 下载安装

1. 下载 `APK/` 文件夹中的安装包
2. 手机上点击安装（提示"未知来源"请在设置中允许）
3. 打开即可使用，无需注册

**系统要求：** Android 7.0+
**应用大小：** 734KB

## 主要功能

### 记账
- 12 个消费分类 + 6 个收入分类，带 Emoji 图标
- 快捷金额按钮（5/10/20/50/100）
- 心情标签（开心/平静/焦虑/后悔等）
- 补记功能：支持补记过去任意日期
- 智能文字导入：输入"奶茶15"自动识别金额和分类
- 截图识别导入：截图支付宝/微信支付页面导入

### 统计
- 月度收支概览 + 环比变化
- 消费日历：净赚绿色、净亏紫色，热力图直观展示
- 趋势图：6 个月收支双线图 + 渐变面积填充
- 支出分类饼图：带图例，超 7 项自动归为"其他"
- AI 理财报告：5 维度评分 + 恩格尔系数 + 智能洞察
- 消费人格测试：6 种人格标签 + 数据概览

### 体验
- 深色模式：浅色 / 深色 / 跟随系统 / 定时切换
- 时间胶囊：给未来的自己写信，到期才能打开
- 微关怀：深夜记账问候、每日首笔鼓励、超支安慰
- 数据导出：CSV / JSON / 分享卡片 / 统计截图
- 数据导入：智能文字 / 截图识别 / 文件导入

## 隐私说明

- 所有数据存储在手机本地（localStorage）
- 不上传任何服务器，不收集任何用户信息
- 无网络权限
- 卸载 APP 即彻底清除所有数据
